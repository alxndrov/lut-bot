## Рассылка 05.11.2026

Согласована пользователем в чате. ncomonetasupport исключён. Предложение для трёх опций (съёмка, монтаж, пакет) — по цене стадии первого открытия экрана курса; VIP не участвует. Цены фиксируются в course_campaign, срок перехода к созданию оплаты ограничен 08.11.2026 00:00 МСК. Уже созданные внешние счета имеют собственный срок действия платёжного сервиса.

Лист «События»: время МСК, Telegram ID, Telegram, имя, действие, подробности, ID события. Прочтение Telegram не предоставляет. «Отправлено» означает успешный ответ API Telegram, «Перешёл к оплате» — открытие нашей ссылки оплаты. Покупка определяется по записи реального платежа курса, совершённого после отправки, независимо от платёжного канала; это покупка после рассылки, не доказательство её причинного влияния.

События сохраняются в SQLite и синхронизируются воркером с периодом 20 секунд; ID защищают журнал от дублей при повторе. Записи отвечающих поступают Дане в админский бот. В A:C листа «Ответы» данные не перезаписываются; D — последнее событие, E — время отправки, F — ответы с сохранением ручного текста. Дополнительные действия видны полностью в журнале.

Однократная отправка: scripts/send_course_offer.py --send (из корня как модуль scripts.send_course_offer). Состояние sending при неясном сетевом результате требует ручной проверки и не повторяется автоматически.

Свободное сообщение получателя рассылки не считается автоматически ответом о курсе. Тема определяется по явному ответу на известное сообщение, нажатию «Есть вопрос» или однозначному содержанию. Неясные сообщения помечаются нейтрально. Явный отзыв о физтоваре при наличии отправленного заказа сохраняется в отзывах без автоматической публикации. Такие сообщения поступают Дане и остаются в журнале, но не добавляются в F как возражения по курсу. Для новых просьб об отзыве сохраняется привязка сообщения к теме, чтобы ответ через Reply имел приоритет.
